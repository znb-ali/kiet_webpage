
# KIET University Website

## Project Description
A static university website developed using HTML, CSS, and JavaScript for the Application of Information and Communication Technology assignment.

The website includes:
- Home section
- About section
- Departments
- Academic programs
- Campus information
- Admission inquiry form
- JavaScript welcome message and form confirmation

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.

Karachi Institute of Economics and Technology (KIET)
